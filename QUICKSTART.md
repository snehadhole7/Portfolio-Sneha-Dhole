### Step 4: Deploy to GitHub (1-2 minutes)

**Option A: Fastest Way - GitHub Web Upload**

1. Create GitHub account at [github.com/signup](https://github.com/signup)
2. Go to [github.com/new](https://github.com/new)
3. Name repo: `portfolio`
4. Click "Create repository"
5. Click "Add file" → "Upload files"
6. Drag & drop: `index.html`, `styles.css`, `script.js`, `README.md`, `assets/` folder
7. Scroll down, click "Commit changes"
8. Go to Settings → Pages
9. Under Source, select "main" branch
10. Save
11. ✅ Your site is live at `https://YOUR-USERNAME.github.io/portfolio`

Wait 1-2 minutes, then visit that URL!


## 🆘 Quick Troubleshooting

**"It doesn't look right locally"**
- Make sure all files are in the same folder
- Clear browser cache (Ctrl+Shift+Del)
- Hard refresh (Ctrl+F5)

**"GitHub Pages isn't working"**
- Wait 2-3 minutes after enabling
- Check Settings → Pages is enabled
- Make sure `index.html` is in root folder
- Clear browser cache

**"My changes didn't show"**
- For local: Refresh browser (Ctrl+F5)
- For GitHub: Wait 1-2 minutes, then hard refresh
- If still no change, check that you pushed correctly

**"I don't know how to edit HTML"**
- Open `index.html` in any text editor (Notepad, VS Code)
- Find the text you want to change using Ctrl+F
- Change it
- Save (Ctrl+S)
- Refresh browser to see changes
